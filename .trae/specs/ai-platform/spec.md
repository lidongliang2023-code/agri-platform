# AI 中台功能与页面原型 · 规格说明

## 一、问题与目标

供应链金融模块已落地融资方端、资金方端、运营风控端的页面原型，但业务流程中的信用评估、风控决策、贷后预警、产品匹配、文档生成、质押估值等关键环节仍依赖人工经验，存在效率低、标准不统一、风险识别滞后等问题。

本次工作目标：在现有产品原型体系中新增 **AI 中台** 专属目录与页面，完整呈现 10 大 AI 智能增强场景的功能与交互原型，使 AI 能力在供应链金融全链路中可视化、可操作、可监控。

## 二、用户角色

| 角色 | 关注场景 |
|---|---|
| 平台运营 / 风控总监 | AI 总览、风控 Agent 集群、贷后预警、核保审批 |
| 客户经理 / 业务拓展 | 信用评估、产品匹配、AIGC 文档 |
| 风控专员 / 反欺诈 | 风控集群、欺诈检测 |
| 贷后管理 / 仓储风控 | IoT 预警、动态质押率 |
| 资产运营 / 商务 | 资金方对接 |
| 技术负责人 / 产品经理 | AI 配置中心 |

## 三、功能需求（10 大 AI 场景）

### P0 核心必做
1. **智能信用评估 Agent**：多源数据融合（政务/产业链/卫星/IoT/软信息）→ 信用评分（1-1000）→ 预授信建议。含对话式交互页与监控页。
2. **智能风控 Agent 集群**：贷前/贷中/贷后全流程多 Agent 协同，D-S 证据理论融合，GNN 反欺诈，自动通过/转人工决策。
3. **IoT + AI 贷后智能预警**：24/7 IoT 数据采集，四级预警（正常/关注/警告/紧急），异常检测 + 时序预测 + 市场风险联动，预警处置工单。

### P1 重要推进
4. **场景化融资产品智能匹配**：自然语言需求解析 → 产品知识库检索 → Top3 推荐 + 方案对比 + 个性化定价。
5. **AIGC 金融文档自动化**：融资合同/担保协议/质押合同/风控报告自动生成，合规条款检查，模板库与历史管理。
6. **存货质押动态质押率调整**：实时公允价值 + 价格预测 + 动态质押率 + 警戒/平仓线触发 + 补货追保。

### P2 扩展能力
7. 智能核保审批 Agent（多模态 OCR + 多 Agent 核验 + 审批决策）
8. 资金方智能对接与资产分发（资产-资金方匹配 + 竞价 + 分发记录）
9. 农业保险 + 期货联动智能定价
10. 农户数字金融助手（对话式）

## 四、非功能需求

- **设计一致性**：复用现有 `theme.css` 设计系统（农业绿 + 科技蓝），AI 场景以紫色（`--violet`）作为智能能力强调色，监控面板复用深色 `.screen` 主题；不修改 `theme.css` 全局规则。
- **纯静态原型**：无构建、无框架、不引入外部依赖，所有交互用内联 JS 实现。
- **导航架构**：AI 中台采用与运营端一致的 `app-shell`（左侧 200px 导航 + 右侧内容），10 大场景通过侧边栏统一入口。
- **数据真实性**：所有数值、案例使用贴近供应链金融业务的合理模拟数据。

## 五、页面清单

| 文件 | 场景 | 类型 |
|---|---|---|
| `ai/index.html` | AI 总览 | 总览 + 10 大 Agent 状态 |
| `ai/credit.html` | 智能信用评估 | 对话式交互 + 监控 |
| `ai/risk.html` | 智能风控 Agent 集群 | 集群面板 + 决策链路 |
| `ai/iot-warning.html` | IoT 贷后预警 | 预警面板 + 处置中心 |
| `ai/product-match.html` | 产品智能匹配 | 对话式匹配 + 方案对比 |
| `ai/aigc-doc.html` | AIGC 文档自动化 | 文档生成 + 合规审查 |
| `ai/pledge-rate.html` | 动态质押率 | 质押率监控 + AI 估值 |

## 六、验收标准

- **rule**：7 个页面全部创建于 `prototype/ai/` 目录，均正确引用 `../assets/css/theme.css` 与 `../assets/js/app.js`。
- **rule**：所有页面控制台无 JS 报错，`data-icon` 图标正常渲染，`data-tab` 切换正常。
- **rule**：AI 中台侧边栏 10 大场景入口可跳转（P0/P1 跳对应页，P2 标注"规划中"）。
- **rule**：原型总览 `index.html` 与运营端 `ops/finance.html` 均有指向 AI 中台的可访问入口。
- **rubric**：每个 P0/P1 页面至少包含：KPI 指标区、核心交互区、AI 能力说明区，且布局与现有原型风格统一。
- **rubric**：监控类页面（风控、IoT 预警、质押率）使用深色科技风，呈现实时数据流与可视化。
