# 农业产业互联网平台 - 物联网模块 Trae Solo 开发提示词

**版本说明**：本提示词基于 Trae-Solo初始化提示词.md
扩展，专用于物联网（IoT）管理模块的开发。

**前置条件**：请先完成公共层（common模块）和主数据模块的基础设施搭建，再开始物联网模块开发。

**模块定位**：物联网模块是平台的感知层，负责连接田间地头的各类传感器、执行器，实现农业生产环境的实时感知与智能控制。

## 一、模块概述

### 1.1 模块定位

物联网模块是农业产业互联网平台的「感知神经」，承担以下核心职责：

  ----------------------------------------------------------------------------------------
  **职责类型**                        **说明**
  ----------------------------------- ----------------------------------------------------
  **设备接入**                        统一接入各类农业物联网设备（传感器、控制器、网关）

  **数据采集**                        实时采集土壤、空气、水质等环境参数

  **监控预警**                        实时监测环境指标，触发阈值告警

  **远程控制**                        下发控制指令到执行设备（灌溉、通风、施肥等）

  **智能联动**                        基于预设规则实现设备自动化控制
  ----------------------------------------------------------------------------------------

### 2.3 MQTT模拟方案（MVP阶段）

由于MVP阶段不接入真实MQTT Broker，采用以下模拟方案：

#### 2.3.1 模拟数据生成器

**// java\
**\@Component\
public class DeviceDataSimulator {\
\
\@Scheduled(fixedRate = 10000) // 每10秒执行一次\
public void simulateDataReport() {\
// 1. 查询所有在线设备\
List\<Device\> onlineDevices = deviceMapper.selectList(\
new LambdaQueryWrapper\<Device\>().eq(Device::getOnlineStatus, 1)\
);\
\
// 2. 为每个设备生成模拟数据\
for (Device device : onlineDevices) {\
DeviceData data = new DeviceData();\
data.setDeviceId(device.getId());\
data.setTemperature(randomValue(15, 35)); // 温度15-35℃\
data.setHumidity(randomValue(40, 90)); // 湿度40-90%\
data.setSoilMoisture(randomValue(30, 80)); // 土壤湿度30-80%\
data.setPh(randomValue(5.5, 7.5)); // pH值5.5-7.5\
data.setReportTime(LocalDateTime.now());\
\
// 3. 存入数据库\
deviceDataService.save(data);\
\
// 4. 触发预警检查\
alertRuleEngine.check(device, data);\
}\
}\
}

#### 2.3.2 模拟控制指令下发

**// java\
**\@Service\
public class ControlSimulator {\
\
/\*\*\
\* 模拟下发控制指令\
\* 实际场景中会通过MQTT发送到真实设备\
\*/\
public void simulateControl(Device device, ControlCommand command) {\
// 1. 记录控制日志\
DeviceControlLog log = new DeviceControlLog();\
log.setDeviceId(device.getId());\
log.setCommandType(command.getType());\
log.setCommandContent(JSON.toJSONString(command));\
log.setStatus(1); // 已下发\
controlLogMapper.insert(log);\
\
// 2. 模拟设备响应（3秒后）\
CompletableFuture.delayedExecutor(3, TimeUnit.SECONDS)\
.execute(() -\> {\
// 模拟设备执行成功\
log.setStatus(2); // 执行成功\
log.setExecuteTime(LocalDateTime.now());\
controlLogMapper.updateById(log);\
\
// 3. 生成执行后的数据变化\
DeviceData data = generatePostControlData(device, command);\
deviceDataService.save(data);\
});\
}\
}

\

}\
}\
}\
