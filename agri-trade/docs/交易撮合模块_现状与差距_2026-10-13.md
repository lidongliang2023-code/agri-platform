## 五、环境注意事项（会反复踩）

1. **端口**：nginx 占 80 / 8080 / 8081 / 8082 / 8084 / 8085 / 8090 / 8190；
   后端：8083 主数据、8093 core-platform、8089 交易、8082 生产（注意与 nginx 的 8082 冲突）。
   8087 / 8088 是 finance / s2b2c 的 upstream 目标。**新增服务前先 `netstat` 确认**。
2. **`mvn spring-boot:run` 在本机不稳**：编译状态文件被后台进程占用（报
   `Error while storing the mojo status`），且后台启动时 mvn → cmd → java 进程链活不下来。
   用 `mvn -o -DskipTests package` + `java -jar` 两步走。
3. **PowerShell 传 maven 参数**：`-Dspring-boot.run.arguments="a b c"` 会被空格拆开、
   应用收到空参数并回落到默认端口 8080。改用环境变量（`SERVER_PORT` 等）。
4. **Maven 本地仓库**：`C:\maven\repository`，必须显式 `-s %USERPROFILE%\.m2\settings.xml`，
   否则 `user.home` 解析成 `C:\` 会去找 `C:\.m2\repository`。
5. **缺依赖就会挡死构建**：本机离线仓库里 **h2 一个版本都没有**、`spring-boot-starter-parent`
   只有 3.0.4 / 3.2.0 / 3.2.4。加依赖前先看仓库里有没有。
6. **`target/` 在本仓库是被 git 跟踪的**（jar 也在内），所以构建会改动受版本控制的文件；
   提交时只 `git add` 源码与配置，不要把 66MB 的 jar 带进提交。
