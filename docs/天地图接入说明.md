# 天地图统一接入说明

生产管理与物联网管理的地图统一使用天地图 Web API，共享组件位于：

- `packages/agri-shared/src/components/TiandituMap.tsx`
- `packages/agri-shared/src/components/TiandituMap.css`
- `packages/agri-shared/src/components/chinaRegionCenters.ts`

## 已接入页面

生产管理：

- 地块列表地图视图：展示地块中心点、GeoJSON 边界，点击进入地块详情。
- 新增 / 编辑地块：点击天地图选点写回 `center_longitude` / `center_latitude`；
  地块边界在天地图上多点绘制（`TiandituBoundaryEditor`，支持撤销 / 清空 / 点击顶点删除，
  实时显示顶点数、面积亩数与周长），保存为 `boundary` GeoJSON。
- 地块详情：按中心点（缺失时用边界质心）展示地块边界与周边底图。
- GIS 地图监管：按省级行政区展示农场分布。
- 运营管理大盘：全国生产区域分布。
- 生产驾驶舱：农场区域分布。
- 生产监控中心与大屏：接入天地图底图。

物联网管理：

- 地块监测地图视图：展示当前筛选地块。
- 地块详情：展示该地块中心点、边界与周边底图。

生产移动端 H5 地块地图也已使用同一天地图密钥。小程序和 App 在配置
`VITE_PRODUCTION_MOBILE_H5_URL` 后，通过 `web-view` 加载同一套移动 H5 地图；
未配置地址时保留平台原生地图组件。

## 配置密钥

天地图密钥无法由代码生成，需要通过天地图控制台申请浏览器端 Key，并配置实际站点的
域名白名单。构建前设置：

```powershell
$env:VITE_TIANDITU_TOKEN = '<天地图浏览器端访问密钥>'
```

也可以在运行时设置：

```js
window.__TIANDITU_TOKEN__ = '<天地图浏览器端访问密钥>'
```

对应示例文件：

- `agri-production/frontend/.env.example`
- `agri-iot/web/.env.example`
- `agri-production/miniprogram/.env.example`

未配置密钥时页面会明确显示“尚未配置天地图访问密钥”，不会回退到其他地图服务。

- 物联网管理 PC：`iot-web@20261027-tianditu-key-r2`

## 坐标口径

- 地块中心点：WGS84 / CGCS2000 经纬度，字段 `center_longitude`、`center_latitude`。
- 地块边界：GeoJSON Polygon 或 MultiPolygon，字段 `boundary`。
- 缺少精确坐标的农场区域数据，按省级行政区代表点聚合展示，不伪造农场坐标。
