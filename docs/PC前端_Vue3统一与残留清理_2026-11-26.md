# PC 前端 Vue 3 统一与残留清理（2026-11-26）

当前共有 19 个 PC 应用工程，全部采用 Vue 3。包含认证登录、认证运营、主数据、门户、生产管理、交易撮合、金融、商城三端、资讯两端、服务两端、监管两端、物联网两端和 AI 运营台。

- AI 运营台新增 `agri-ai/frontend`，Vue 3 管理页面外壳、状态、导航及生命周期，保留原有业务表单渲染与接口，避免迁移时丢失场景、提示词、模型接入和熔断功能。Maven 自动构建前端并随 jar 打包。
- 所有 PC 应用统一使用根 `pnpm-lock.yaml`；移除 PC 目录重复锁文件、生产前端锁文件备份和旧 Vite 时间戳缓存，共 18 个文件。安装后的依赖树没有 React 运行时。
- 清理活动源码、页面提示、共享库注释和回归脚本中的旧框架引用；`.tsx` 保留为 Vue JSX，不作为框架残留删除。
- 历史设计和验收文档记录当时实施情况，其中的旧选型描述不代表当前架构，以本记录和自动检查结果为准。
- 根锁文件的 `react-is` 来自移动端 `uni-automator → Jest → pretty-format`，属于测试工具的类型判断依赖；PC 应用没有引用它，不作为 React 运行时移除。

验证结果：

1. 19 个 PC 工程原有 build 命令全部通过（含各工程已有的 TypeScript / vue-tsc 检查）。
2. `node ops/ci/verify.mjs --only workspace`：29 项通过，其中包含新增的 PC 框架检查。
3. `node agri-ai/frontend/scripts/smoke.mjs`：生产产物在真实 Chromium 浏览器中通过登录会话、权限拦截、7 个页面、场景弹窗、提示词变量、调试提交、模型弹窗、通知、刷新和失败提示回归；接口使用隔离测试数据。
4. `mvn -f agri-ai/pom.xml generate-resources -DskipTests`：前端构建集成通过。

后续执行 `pnpm check:pc-framework` 排查框架依赖、入口、Vite 插件及锁文件；执行 `pnpm build:pc` 构建全部 PC 工程。框架检查已纳入统一 CI 的 workspace 检查组。

本次更新源码和本地构建产物，没有切换网关发布指针，也没有重启服务。线上与当前运行实例需后续部署才会使用新产物。
