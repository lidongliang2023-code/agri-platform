## 检查口径

本次按规范中的设计令牌和组件约束检查：

- 页面背景 `#F5F6FA`，内容卡片白底，主色 `#2D8F4E`，侧栏 `#001529`。

## 静态检查结果

### 已符合或基本符合

- 13 个已接入共享 PC 规范的工程入口都加载了 `shared/pc-ui-v1.css` 或对应公共入口。
- 共享样式覆盖了侧栏、顶栏、内容区、卡片、表格、按钮、输入控件、状态标签、弹窗和焦点样式。
- 生产、物联网、信息资讯、政府监管、用户中心及综合服务运营端的结构均能套用 240px 侧栏、64px 顶栏和浅灰内容区。
- 表格公共增强器已覆盖 Ant Design、Element Plus 和项目内原生数据表格，并支持数字列、状态列、编码列和操作列的统一表现。
- 共享样式已提供 1024px 下侧栏收缩到 80px 的规则，以及内容区横向滚动处理。

### 不完全符合或需要处理

1. **供应链金融专用样式冲突（已修正发布，最终补丁待复验）**
   - 更正：实际入口是 `src/main.js`，原本已经引用 `shared/pc-ui-v1.mjs`，不能通过 App.vue 未引用就判定未接入。
   - 专用渐变卡片、圆角、按钮及窄窗口选择器与公共规范冲突，本轮已按规范修改。
   - 最终版本为 `20261121-finance-pc-v4`。v3 已检查融资方五个页面；v4 的断点优先级、首页按钮及36处表格列属性修正后没有再次浏览器验证。资金方和运营端未登录逐页验收。

2. **主数据端残留旧色值（2026-11-21 已修正发布）**
   - `global.scss` 中旧主色 #1890ff、旧背景 #f5f5f5 已清理，主数据 src 扫描这两种色值均为 0 命中。
   - 更正检查范围：当前 index.html 使用 Vue main.ts；global.scss 未被当前入口引用，属于历史样式残留。本次同时修正实际 App.vue 组件主题及 index.css 正文/背景色。
   - 已发布 `20261121-mdm-pc-colors-v3`；构建及代表页面检查结果见文末，不代表全部业务页面验收通过。

3. **商城供应商端未同步本轮发布版本**
   - `mall-supplier` 当前仍是 `20261103-supplier-auth-fix-r3`。
   - 因版本不是 `20261121-pc-ui-v2`，本端不能判定已按本轮 PC 规范更新。
   - 建议：先确认供应商端是否继续作为独立 PC 端使用；若继续使用，按 `mall-channel` 的规范接入和重新发布。

4. **页面级样式仍有较多自定义阴影和大圆角**
   - 交易、门户等工程保留较多页面级 `box-shadow` 和大于 12px 的 `border-radius`。
   - 其中一部分属于首页视觉卡片或浮层，不能仅凭静态命中判定错误；但平铺业务卡片若继续使用 14px 及以上圆角，就不符合规范的卡片层级约束。
   - 建议：对交易商品创建、门户首页、详情卡片逐页确认，把平铺卡片收敛到 8px，把弹窗保留 12px。

## 本轮结论

当前 PC 端整体视觉框架已经统一，13 个已接入共享规范的工程在代表性首页和运营大盘上基本符合 V1.0；**不能认定所有 PC 页面全部符合设计规范**。

优先级建议：

1. 高：供应链金融接入共享 PC 规范并重新构建；商城供应商端确认并同步版本。
2. 中：复核交易和门户的平铺卡片大圆角、阴影。主数据目标旧色值已于2026-11-21修正发布。
3. 中：补做各端详情、表单、弹窗、空状态、错误状态和权限场景逐页验收。
4. 低：登录 AI 中台后再检查业务工作区和权限差异。

本轮只做读取、静态扫描、浏览器打开和截图检查，未修改源码、未重新构建、未发布版本、未发送消息、未提交业务数据或删除文件。
