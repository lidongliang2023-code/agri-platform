# 子系统与移动端独立部署手册

机器可读清单为 `ops/modules/catalog.json`。检查所有部署单位的端口和源码状态：

```powershell
node ops/modules/status.mjs
node ops/modules/status.mjs trade
node ops/modules/status.mjs --json
```

检查所有移动端的三目标构建能力：

```powershell
node ops/modules/audit-mobile.mjs
```

## 独立部署边界

- 每个前端拥有独立源码目录、发布代号、不可变版本目录和当前版本指针。
- 发布或回滚一个前端只切换对应 `bucket/<app>/index.html`，不重建其他子系统。
- 每个子系统后端可独立启动；共同依赖为统一认证、MySQL 和 Redis。
- 生产环境可使用独立域名、独立主机或独立容器，只需配置网关和 API 地址。
- PC 用户端、运营端和移动端互不共用静态产物。

## 移动端构建

在每个移动工程目录执行：

```powershell
pnpm install
pnpm run build:h5
pnpm run build:mp-weixin
pnpm run build:app
```

产物位置：

- H5：`dist/build/h5`
- 微信小程序：`dist/build/mp-weixin`
- APP 资源：`dist/build/app`，由 HBuilderX 导入后执行 Android/iOS 原生打包

正式发布前必须配置：

- 微信小程序 AppID 和已备案的 HTTPS request 合法域名。
- APP 的 API/认证 HTTPS 域名、应用名称、图标、包名、签名和隐私权限声明。
- H5 的 API/认证地址，或使用同域网关代理。
- 各工程 `.env.example` 中的 API、认证和开发代理变量。

## 独立主机部署

1. 按源码目录单独克隆或复制对应子系统。
2. 安装对应 Node.js/pnpm、JDK 17 和 Maven。
3. 按 `.env.example` 配置 API、认证与数据库地址。
4. 后端执行 Maven `package`，前端执行对应 `build`。
5. 静态产物部署到任意 HTTPS 静态站点；APP 与小程序走各自发布平台。
6. 更新统一认证客户端的 redirect URI 白名单。

生产环境不得使用 `localhost` 地址，移动端 API 必须为微信/APP 允许的 HTTPS 域名。
