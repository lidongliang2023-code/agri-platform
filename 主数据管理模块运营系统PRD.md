## 一、文档概述

### 1.1 PRD目的

本文档为农业产业互联网平台·主数据管理模块的**运营管理系统**产品需求文档（PRD），旨在明确主数据运营管理后台的功能需求、业务流程、接口设计、权限控制及非功能性要求，为开发团队提供完整的运营系统开发依据。

主数据运营系统是平台的核心基础设施管理工具，与面向业务用户的用户端系统形成互补关系，为平台运营团队提供租户管理、用户管理、权限审计、数据治理、系统运维等全链路运营支撑能力。

### 1.2 运营管理系统定位

主数据模块的运营管理系统与其他业务模块的运营系统有本质区别：

| 系统类型 | 管理对象 | 核心诉求 | 系统入口 |
|---------|---------|---------|---------|
| **业务模块运营系统** | 业务数据（农场、订单、溯源等） | 业务运营、流程审批、数据分析 | Web管理后台 |
| **主数据运营系统** | 平台基础设施（租户、用户、权限、数据标准） | 基础设施管理、多租户治理、数据质量保障 | Web管理后台 |

**核心差异化价值**：
- **租户治理**：多租户全生命周期管理、配额配置与监控、数据隔离保障
- **数据治理**：数据标准统一管理、数据质量检测与改进、数据资产可视化
- **权限安全**：RBAC权限精细管控、权限变更审计、异常权限检测

| 权限审计 | 权限配置/变更 | 运营配置 → 用户端生效 |
| 数据标准 | 字典/编码规则 | 运营发布 → 用户端使用 |
| 数据质量 | 数据质量反馈 | 用户使用 → 质量问题上报 → 运营处理 |
| 分发监控 | 数据同步状态 | 运营监控 → 异常告警 |

| 指标名称 | 指标要求 | 说明 |

### 7.3 安全性要求

| 要求项 | 要求内容 | 说明 |
|-------|---------|------|
| 身份认证 | 账号密码+验证码双因素 | 运营后台登录认证 |
| 会话管理 | 30分钟无操作自动登出 | 保护账号安全 |
| 权限控制 | RBAC细粒度权限控制 | 基于角色分配权限 |
| 操作审计 | 全部操作记录审计日志 | 便于问题追溯 |
| 敏感数据 | 加密存储、敏感字段脱敏 | 保护用户隐私 |
| 传输安全 | HTTPS全链路加密 | 数据传输安全 |
| 密码策略 | 复杂度要求+定期更换 | 账号安全 |
